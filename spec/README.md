# Specifications

| File | Contents |
|---|---|
| `claimset-v0.43.md` | The claimset format: papers as structured, self-contained claims |
| `lab-record-v0.22.md` | The lab record: the append-only log of research from which claimsets are distilled |
| `claimset-revision-v0.6.md` | Revision: reviews of a published claimset, the author's response, revised versions, disputes and scores |
| `extensions/` | Extensions of the claimset format, one per kind of work, each with its own version; `extensions/README.md` is the registry |

Every claimset version from the baseline (v0.39) is kept here for good, since files of those versions stay valid under their own rules (claimset §2.6); so is the previous version of the other specifications. Bugs are corrected in them under *Errata*. Earlier drafts are in the project's design history.
